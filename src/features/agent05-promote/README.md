## 业务规则要点

- **质量评分**：五维等权各 20 分；≥90 优秀（入优秀案例库）、80-89 良好、70-79 合格、<70 不合格（**自动触发重点复盘**）
- **复盘触发**：7 类条件（评分<70 / 申诉改判 / 复议撤销 / 诉讼败诉 / 社会影响大 / 新型违规首例 / 指定复盘）
- **复盘五步法**：案件回顾 → 问题剖析 → 原因分析（制度/流程/人员/技术）→ 改进措施 → 经验教训
- **模型迭代五步**：AI 生成建议 → 算法工程师审核 → 业务专家确认 → 灰度发布 → 全量生效（**支持一键回滚**）
- **监控阈值**：准确率 < 85% 或误报率 > 10% 自动预警
- **三端推送差异**：医院端（合规指引/政策解读/违规警示）· 医保端（监管动态/业务培训/典型案例）· 公众端（政策科普/就医指引/防骗提示）
- **素材脱敏**：机构名称、人员姓名、详细地址、联系方式、身份证号全部脱敏，AI 生成 + 人工审核后发布
