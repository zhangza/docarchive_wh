## 编码规则

- **文号**：机关代字 + 文书类型代字 +〔年份〕+ 流水号，如 `芜医保罚〔2026〕012号`
- **代字**：22 种文书类型各有独立代字（检/派/记/询/证/调证/告/申辩/听/整/约/追/暂停结/暂停协/解/罚/移/送回/执/卷/结/备）
- **文号管理**：按「类型 + 年度」独立编号，从 001 起连续；生成即占用，作废不回收避免重号
- **档号**：`YJ-ZF-2026-NNN`；案卷号 `芜医保档〔2026〕NNN号`
