# 专项任务管理智能体 — 详细功能设计

> 本文档用于前端 Vibe Coding 开发，聚焦业务流程与功能逻辑，所有数据均为 Mock 数据。

---

## 一、模块概述

### 1.1 模块定位

专项任务管理智能体是医保基金监管全流程的**任务调度中枢**，承担"线索聚类成任务—任务标准化生成—精准派达—全周期进度管控—结果自动汇总"核心职能，将分散的疑点线索转化为规范、可执行、可跟踪的监管检查任务，实现专项检查任务全生命周期自治管理。

### 1.2 解决的核心问题

- 人工归并线索效率低、立项标准不统一
- 重复立项、交叉立项导致资源浪费
- 人工线下派单慢、签收无跟踪、通知不到位
- 任务进度不透明、超期无人管、全靠人工催办
- 多源结果汇总难、人工撰写慢、口径不统一

### 1.3 与其他智能体的关系

| 上游输入 | 本智能体 | 下游输出 |
|---|---|---|
| 疑点线索管理智能体（已确认线索） | 专项任务管理智能体 | → 疑点线索管理智能体（线上筛查/线下核查任务执行） |
| 动态规则引擎（任务规则配置） | | → 违规处置智能体（任务结果流转） |
| 组织与权限（人员/分组配置） | | → 文书生成智能体（任务文书生成） |

## 二、业务流程

### 2.1 整体业务流程

```
[已确认疑点线索池]
       ↓
[线索智能聚类] → 按区域/机构/科室/违规类型/风险等级归并
       ↓
[合并去重] → 剔除重复、交叉线索
       ↓
[任务要素生成] → 自动预填检查范围、疑点清单、时限、责任人、人员分组
       ↓
[任务审批确认]（可选）→ 监管人员审核调整后确认立项
       ↓
[任务自动派发] → 批量/定向/分级派发，限时签收，同步生成空白文书
       ↓
[任务执行] → 机构线上自查 + 监管人员线下核查（由疑点线索智能体承接）
       ↓
[进度管控] → 全程可视化、超时预警、自动督办
       ↓
[结果自动整合] → 汇总线上筛查、线下核查、申诉、佐证材料
       ↓
[初步结果生成] → AI生成违规内容、违规金额、问题性质、处理意见
       ↓
[结果推送] → 推送被检机构 + 流转违规处置智能体
```

### 2.2 各子流程说明

**子流程 A：任务生成流程**
1. 从线索池拉取已确认、待立项的疑点线索
2. 按聚类维度自动归并同类线索（同一机构多疑点合并为一个任务）
3. 自动合并去重，避免重复立项
4. 自动生成任务要素：任务名称、检查范围、疑点清单、检查时限、责任检查组、人员分组
5. 支持人工调整任务要素后确认立项
6. 生成唯一任务编号，进入任务库

**子流程 B：任务派发流程**
1. 任务确认后，按派发规则自动匹配承办检查组/人员
2. 支持批量派发（多任务一次派发）、定向派发（指定人员）、分级派发（按风险等级匹配对应级别检查组）
3. 任务秒级推送至承办人员，同步推送至被检机构（如需要）
4. 限时签收，未签收自动提醒并升级
5. 派发时同步生成检查通知书、检查记录单等空白文书

**子流程 C：进度管控流程**
1. 任务各节点状态实时同步（派发、签收、自查、核查、申诉、处置、结案）
2. 以流程/泳道图可视化展示进度
3. 临期自动预警，超期自动标红，一键催办
4. 多渠道提醒（站内信、短信）
5. 任务看板统计各状态任务分布

**子流程 D：结果管理流程**
1. 任务执行完成后，自动整合线上筛查结果、线下核查结果、申诉材料、佐证证据
2. AI自动生成初步检查结果：违规内容、违规金额、问题性质、处理意见
3. 人工复核修正初步结果
4. 结果正式推送被检机构，告知申诉权利
5. 结果流转至违规处置智能体进行后续处置

## 三、功能详细设计

### 3.1 任务智能生成

#### 3.1.1 线索智能聚类

**功能描述**
按区域、机构、科室、违规类型、风险等级自动归并同类线索，将分散疑点整合为有针对性的检查任务。

**业务规则**
- 聚类维度（可组合）：统筹区、机构、科室、违规类型、风险等级、时间范围
- 聚类优先级：机构 > 违规类型 > 风险等级 > 科室 > 区域
- 聚类规则：
  - 同一机构多条线索 → 合并为一个机构检查任务
  - 同一区域多家机构同类违规 → 可合并为一个专项检查任务
  - 高风险线索优先单独成任务，确保快速响应
- 聚类结果展示：以树状/分组形式展示聚类结果，支持人工调整分组
- 聚类统计：每组线索数量、涉及机构数、疑似违规总金额、风险等级分布

**输入**
- 已确认待立项线索列表（线索ID、机构、违规类型、风险等级、疑似金额、科室、区域）

**输出**
- 聚类分组结果（分组ID、分组名称、包含线索列表、统计信息）

#### 3.1.2 合并去重

**功能描述**
自动剔除重复、交叉线索，避免重复立项，确保任务不重叠、不遗漏。

**业务规则**
- 重复判定维度：同一参保人 + 同一就诊记录 + 同一违规类型 → 重复线索
- 交叉判定：同一机构同一时间段内，多个线索涉及同一批费用明细 → 交叉线索
- 去重策略：
  - 完全重复：保留疑似金额最大、置信度最高的一条，其余标记为"已合并"
  - 部分交叉：合并为一条线索，汇总违规金额，关联原始线索ID
- 去重结果展示：展示去重前后数量对比、被合并线索列表、合并理由
- 人工确认：系统自动去重后，支持人工审核确认，可恢复误合并线索

**输入**
- 聚类分组后的线索列表

**输出**
- 去重后的线索列表 + 合并记录

#### 3.1.3 任务要素生成

**功能描述**
自动预填检查范围、疑点清单、时限、责任人与人员分组，生成标准化任务要素，减少人工录入。

**业务规则**
- 任务名称自动生成：[机构/区域] + [违规类型/检查类型] + [时间] + 检查任务
- 检查范围：根据聚类线索自动汇总涉及机构、科室、时间段、违规类型
- 疑点清单：自动关联去重后的线索列表，含线索ID、违规类型、疑似金额、风险等级
- 时限自动计算：
  - 日常稽核：15个工作日
  - 专项检查：30个工作日
  - 飞行检查：7个工作日
  - 联合督查：45个工作日
- 责任人/分组推荐：根据机构辖区、违规类型、检查组专长自动推荐承办组
- 检查方式推荐：高风险→现场检查为主，中风险→线上+现场结合，低风险→线上自查为主

**输入**
- 去重后的聚类分组信息
- 组织人员配置（检查组、人员、专长、辖区）

**输出**
- 标准化任务要素（待人工确认）

#### 3.1.4 多类型任务

**功能描述**
支持专项检查、日常稽核、飞行检查、联合督查等多种任务类型，适配不同监管场景。

**业务规则**
- 任务类型及特点：
  - 专项检查：针对特定违规类型/领域，范围广、周期长（30工作日），需制定检查方案
  - 日常稽核：常规性、随机性检查，周期中等（15工作日）
  - 飞行检查：不预先告知、突击性检查，周期短（7工作日），高风险线索优先
  - 联合督查：多部门联合（医保+卫健+公安+市监），周期长（45工作日），需协调多部门
- 不同类型任务的流程节点、文书模板、审批层级差异化配置
- 任务类型可在生成时选择，也可由系统根据线索特征推荐

### 3.2 任务自动派发

#### 3.2.1 多方式派发

**功能描述**
支持批量派发、定向派发、按风险分级派发，实现任务精准直达承办人员和机构。

**业务规则**
- 批量派发：选中多个任务，一次派发至同一检查组/人员，适合同类任务集中处理
- 定向派发：指定具体承办人/检查组，不受辖区/专长限制，适合特殊任务安排
- 分级派发：
  - 高风险任务 → 市级检查组/资深稽核员
  - 中风险任务 → 区县级检查组/普通稽核员
  - 低风险任务 → 机构自查为主，监管人员抽查
- 派发规则可配置：辖区匹配、专长匹配、工作量均衡、回避规则
- 派发时同步通知被检机构（飞行检查除外）

**输入**
- 已确认立项的任务列表
- 派发方式选择、派发对象配置

**输出**
- 派发记录、任务状态更新为"已派发"

#### 3.2.2 限时签收

**功能描述**
任务秒级推送、限时签收，未签收自动提醒并升级，确保任务及时响应、责任到人。

**业务规则**
- 签收时限：任务派发后24小时内必须签收（可配置）
- 推送方式：系统站内消息 + 短信通知 + 移动端APP推送
- 提醒升级机制：
  - 派发后4小时未签收 → 系统自动提醒
  - 派发后12小时未签收 → 短信提醒承办人 + 抄送组长
  - 派发后24小时未签收 → 标记超期，升级通知分管领导，记录考核
- 签收确认：承办人查看任务详情后确认签收，签收时间精确到秒
- 拒签处理：承办人可申请拒签并说明理由（如辖区不符、回避情形），由调度人员重新派发
