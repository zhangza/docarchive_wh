# 疑点线索管理智能体 — 详细功能设计

> 本文档用于前端 Vibe Coding 开发，聚焦业务流程与功能逻辑，所有数据均为 Mock 数据。

---

## 一、模块概述

### 1.1 模块定位

疑点线索管理智能体是医保基金监管全流程的**风险感知与初判中枢**，承担"发现问题—初步甄别—线上核查—线下取证—申诉受理"全链条职能，是整个监管体系的第一道防线，为后续专项任务调度、违规处置提供精准线索输入。

### 1.2 解决的核心问题

- 线索发现被动滞后，依赖人工翻数据
- 多源数据割裂，无法交叉验证发现隐蔽违规
- 高低风险线索混杂，研判靠个人经验
- 机构自查与医保数据脱节，材料反复补正
- 现场取证繁琐，纸质资料易丢失
- 机构申诉渠道不畅，争议难追溯

### 1.3 与其他智能体的关系

| 上游输入 | 本智能体 | 下游输出 |
|---|---|---|
| 全量数据比对引擎、动态规则引擎、知识图谱 | 疑点线索管理智能体 | → 专项任务管理智能体（线索聚类生成任务） |
| | | → 违规处置智能体（核查确认后的违规线索） |
| | | ← 成果宣教智能体（复盘优化结果反哺模型） |

## 二、业务流程

### 2.1 整体业务流程

```
[多源数据接入融合]
       ↓
[智能比对分析引擎] → 五类数据比对场景（药品/病历/处方/检查/就医行为）
       ↓
[智能预警] → 自动识别违规疑点 → 风险分级分类 → 生成标准化线索
       ↓
[线索研判] → AI研判建议 + 人工确认 → 分流：高风险/中风险/低风险
       ↓
   ┌─── 高风险/存疑 ───→ [线上筛查] 机构在线自查
   │                         ↓
   │                    自查数据自动比对
   │                         ↓
   │              ┌─ 合理说明 → 结案归档
   │              ├─ 存疑线索 → [线下核查] 现场取证
   │              └─ 违规苗头 → 直接进入违规确认
   ↓
[线下核查] → OCR采集 + 证据回传 → 核查结论
       ↓
[机构申诉]（可选）→ 机构提交申诉 → AI初核 → 复核结论
       ↓
[线索全周期管理] → 状态跟踪 + 误判反馈沉淀 → 推送至专项任务/违规处置
```

### 2.2 各子流程说明

**子流程 A：线索生成流程**
1. 多源数据实时接入（结算、病历、处方、PACS、进销存）
2. 智能比对引擎自动扫描，发现数据不一致/逻辑矛盾
3. 规则引擎+大模型双驱动识别违规疑点
4. 自动标注风险等级（高/中/低）、违规类型、涉事主体
5. 生成唯一线索编号，进入标准化线索库

**子流程 B：线索研判流程**
1. 稽核员在工作台查看待办线索
2. 系统展示线索详情、命中明细、AI研判建议（结论/依据/置信度）
3. 临床合理性判定（区分违规与慢病长处方等合理场景）
4. 知识图谱一键溯源（参保人-医生-机构-药品-费用关系）
5. 人工确认采纳/驳回，形成研判结论

**子流程 C：线上筛查流程**
1. 任务派发到定点医药机构
2. 机构在线填写说明、上传佐证、提交自查报告
3. 系统自动比对自查数据与医保原始数据，差异标红
4. 材料智能校验（完整性/关联性），提示补正
5. 自动输出初筛结论：合理说明 / 存疑线索 / 违规苗头

**子流程 D：线下核查流程**
1. 按疑点自动生成现场核查事项清单
2. 移动端现场取证：OCR拍照识别处方/病历/票据
3. 病历核验、处方比对、库存盘点、问询笔录记录
4. 证据实时回传固化，电子签名留痕（支持离线操作）
5. 形成现场核查结论

**子流程 E：机构申诉流程**
1. 机构对初筛/核查结果有异议，在线提交申诉
2. 上传申诉理由、医学依据、佐证材料
3. AI自动校验材料合规性，辅助研判申诉合理性
4. 监管人员结合核查结果+申诉内容进行最终复核
5. 形成申诉复核结论，反馈机构

## 三、功能详细设计

### 3.1 全量数据比对

#### 3.1.1 多源数据接入融合

**功能描述**
接入医保结算、电子病历、处方、PACS检查报告、药品进销存、诊疗记录等多源数据，完成数据融合与标准化映射，为跨源比对分析奠定基础。

**业务规则**
- 数据来源包括：医保结算库、电子病历库、处方库、PACS/LIS系统、药店进销存系统、医院HIS系统
- 数据接入方式：实时接口推送 + 定时批量同步
- 数据标准化：统一药品编码（医保药品目录编码）、诊疗项目编码、机构编码、人员证件号
- 数据质量校验：接入时自动检查完整性、一致性，异常数据标记并告警

**输入**
- 各数据源系统的原始数据（JSON/XML/数据库表）

**输出**
- 标准化融合后的数据集，供比对分析引擎调用

#### 3.1.2 智能比对分析引擎

**功能描述**
基于数据间关联关系，内置多类比对算法模型，自动识别跨源数据不一致、异常关联、逻辑矛盾等问题，生成疑点线索并推送至线索研判环节。

**业务规则**
- 比对触发方式：实时流式比对（数据接入即比对）+ 定时全量比对（每日凌晨）
- 比对算法：数值差异比对、逻辑一致性比对、关联关系比对、统计异常比对
- 疑点生成条件：比对差异超过预设阈值 → 自动生成疑点线索
- 疑点分级：根据差异金额、差异比例、违规可能性自动标注高/中/低风险
- 引擎可配置：比对规则、阈值、比对范围支持动态调整

**输入**
- 标准化融合后的多源数据集
- 比对规则配置（规则ID、比对字段、阈值、适用范围）

**输出**
- 比对疑点清单（疑点ID、比对类型、差异描述、差异金额、风险等级、涉事主体）

#### 3.1.3 药品进销存与结算比对分析

**功能描述**
比对药店/医院药品进货量、库存量与医保结算报销量，识别超量销售、账实不符、虚假销售、药品回流等疑点。

**业务规则**
- 比对维度：按机构 + 药品 + 时间段（日/周/月）
- 核心比对逻辑：
  - 结算报销量 > 进货量 + 期初库存量 → 超量销售疑点
  - 结算报销量与进销存出库量差异 > 5% → 账实不符疑点
  - 同一药品短期内大量结算但无进货记录 → 虚假销售疑点
  - 药品回流：参保人购药后短期内同药品在其他机构大量结算
- 金额计算：差异数量 × 医保结算单价 = 疑似违规金额

**输入**
- 药品进销存数据（进货、销售、库存）
- 医保结算药品费用明细

**输出**
- 药品比对疑点清单，推送至线索库

#### 3.1.4 电子病历与结算比对分析

**功能描述**
比对病历记载的诊断、诊疗项目、用药与医保结算费用明细，识别串换项目、无指征收费、过度诊疗、病历与费用不符等疑点。

**业务规则**
- 比对维度：按就诊记录（门诊号/住院号）+ 结算明细
- 核心比对逻辑：
  - 结算有收费项目但病历无对应记载 → 无指征收费/虚记费用
  - 病历诊断与收费项目适应症不符 → 串换项目
  - 收费项目数量超出病历记载诊疗次数 → 过度诊疗/重复收费
  - 病历用药与结算药品不一致 → 串换药品
- 临床合理性校验：结合诊断、病情、诊疗规范判断收费合理性

**输入**
- 电子病历数据（门诊病历/住院病历、诊断、医嘱、诊疗记录）
- 医保结算费用明细

**输出**
- 病历费用比对疑点清单

#### 3.1.5 处方与结算比对分析

**功能描述**
比对处方开具的药品名称、剂量、频次、疗程与医保结算数据，识别超量开药、重复开药、串换药品、超适应症用药等疑点。

**业务规则**
- 比对维度：按处方号 + 结算明细
- 核心比对逻辑：
  - 结算药品数量 > 处方开具数量 → 超量开药
  - 同一参保人短期内同一药品在多机构/多医生处开具 → 重复开药
  - 结算药品与处方药品名称/规格不一致 → 串换药品
  - 药品适应症与处方诊断不符 → 超适应症用药
  - 开药频次/疗程超过医保规定限额 → 违规开药
- 限量规则：急性病不超过3日量、慢性病不超过7日量、长处方不超过12周

**输入**
- 处方数据（处方号、药品、剂量、频次、疗程、诊断、开方医生）
- 医保结算药品费用明细

**输出**
- 处方结算比对疑点清单

#### 3.1.6 检查检验与收费比对分析

**功能描述**
比对 PACS/LIS 等系统实际检查检验报告与结算收费项目，识别虚记费用、重复收费、套餐式检查、做少收多等疑点。

**业务规则**
- 比对维度：按检查申请号 + 报告记录 + 结算明细
- 核心比对逻辑：
  - 结算有收费但无检查报告 → 虚记费用
  - 同一检查项目多次收费但仅一次报告 → 重复收费
  - 无临床指征的多项检查打包收费 → 套餐式检查
  - 报告显示检查部位/项目少于收费项目 → 做少收多
- 报告时效性：检查后24小时内应出报告，超时未出标记异常

**输入**
- PACS影像报告、LIS检验报告
- 检查检验申请记录
- 医保结算检查检验费用明细

**输出**
- 检查检验收费比对疑点清单

#### 3.1.7 参保人就医行为跨源比对分析

**功能描述**
跨机构、跨时段比对同一参保人的就医、住院、开药、结算记录，识别重复住院、分解住院、频繁就医、超量购药、冒名就医等疑点。

**业务规则**
- 比对维度：按参保人 + 时间窗口（日/周/月/年）+ 跨机构
- 核心比对逻辑：
  - 同一参保人同一时段在多家机构住院 → 重复住院
  - 出院后短期内（<7天）因同诊断再次入院 → 分解住院
  - 短期内频繁就医（月门诊>15次）→ 频繁就医
  - 多机构累计购药超限定剂量 → 超量购药
  - 就医记录与参保人年龄/性别/健康状况严重不符 → 冒名就医
- 时间窗口可配置：默认月维度，支持自定义

**输入**
- 参保人基本信息
- 跨机构就医结算记录（门诊、住院、购药）
- 电子病历摘要

**输出**
- 参保人就医行为异常疑点清单

### 3.7 线索全周期管理
