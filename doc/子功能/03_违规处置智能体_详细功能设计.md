# 违规处置智能体 — 详细功能设计

> 本文档用于前端 Vibe Coding 开发，聚焦业务流程与功能逻辑，所有数据均为 Mock 数据。

---

## 一、模块概述

### 1.1 模块定位

违规处置智能体是医保基金监管全流程的**执法处置中枢**，承担"违规确认—分类处置—基金追回—整改跟踪—闭环销号—台账沉淀"全链路职能，将核查确认的违规线索转化为合法、规范、可执行的处置决定，实现"确认—处置—整改—销号"闭环管理，守住基金安全监管底线。

### 1.2 解决的核心问题

- 定性靠经验、金额核算繁、责任难界定
- 协议处理、行政处罚、移送司法路径不清、程序严易出错
- 追回进度不清、到账无跟踪
- 任务资料分散、检查标准与经验无法复用
- 问题整改无人盯、整改不实、屡查屡犯
- "查完就完"，处置形不成闭环

### 1.3 与其他智能体的关系

| 上游输入 | 本智能体 | 下游输出 |
|---|---|---|
| 专项任务管理智能体（任务结果） | 违规处置智能体 | → 文书生成智能体（处置文书生成） |
| 疑点线索管理智能体（核查结论、申诉结果） | | → 成果宣教智能体（处置结果、案例沉淀） |
| 政策法规案例库（处置依据） | | → 机构端（处置决定送达、整改要求） |

## 二、业务流程

### 2.1 整体业务流程

```
[任务结果/核查结论]
       ↓
[违规智能确认] → AI辅助定性 + 金额核算 + 责任界定
       ↓
[双人复核] → 重大定性/处罚事项双人复核、电子签名
       ↓
[检查报告生成] → 自动生成规范检查报告
       ↓
[结果推送] → 正式推送被检机构，告知申诉权利
       ↓（机构无异议/申诉期满）
[分类处置]
   ├── 协议处理（约谈/拒付/追回/暂停结算/暂停协议/解除协议）
   ├── 行政处罚（立案→调查→告知→听证→决定→送达→执行）
   └── 移送处理（涉嫌犯罪→公安 / 违纪→纪检）
       ↓
[基金追回] → 追回台账登记 → 到账核销跟踪
       ↓
[整改跟踪] → 下达整改清单 → 机构反馈 → 监管复查
       ↓
[闭环销号] → 销号条件核验（定性/处置/追回/整改/文书齐备）
       ↓
[销号审批] → 核准销号 + 信用联动
       ↓
[台账与经验沉淀] → 全流程归档 + 统计分析 + 案例沉淀 + 复盘优化
```

### 2.2 各子流程说明

**子流程 A：违规确认流程**
1. 接收任务结果/核查结论/申诉复核结果
2. AI辅助开展违规定性（违规类型、问题性质）、金额核算（违规本金、涉及基金、处罚金额）、责任界定（机构责任、科室责任、个人责任）
3. 重大定性与处罚事项实行双人复核、电子签名
4. 确认后自动生成规范检查报告
5. 复核通过后将结果正式推送被检机构，告知申诉权利与时限

**子流程 B：分类处置流程**
1. 根据违规性质、金额、情节，自动匹配处置类型
2. 协议处理：约谈、拒付、基金追回、暂停结算、暂停/解除服务协议，生成协议处理文书
3. 行政处罚：自动生成处罚决定书等成套案卷，支持在线签章与电子送达，履行告知、听证程序
4. 移送处理：涉嫌犯罪移送公安、违纪移送纪检，生成移送文书与清单
5. 智能匹配政策、法规、案例作为定性处置依据

**子流程 C：基金追回流程**
1. 登记应追、已追、未追金额及追回方式（主动退回、扣缴、强制执行）
2. 上传到账凭证，跟踪追回进度
3. 到账后核销，更新追回状态
4. 未按期追回的，自动提醒并升级处置措施

**子流程 D：整改跟踪流程**
1. 逐项下达整改问题、要求与办理时限
2. 机构在线反馈整改情况，上传整改佐证
3. 监管审核复查是否通过，不通过的退回重改
4. 整改期满未完成的，自动督办并纳入信用记录

**子流程 E：闭环销号流程**
1. 自动校验销号条件：定性完成、处置执行、基金追回、整改到位、文书齐备
2. 满足条件后提交销号审批
3. 核准销号并闭环标识
4. 按规定将处置结果联动机构与个人信用记录

## 三、功能详细设计

### 3.1 违规智能确认

#### 3.1.1 AI辅助定性

**功能描述**
辅助开展违规定性、金额核算与责任界定，是违规处置的关键起点，确保定性准确、金额精准、责任清晰。

**业务规则**
- 违规定性：
  - 根据核查结论、证据链、申诉复核结果，AI辅助认定违规类型（一级+二级分类）
  - 认定问题性质：一般违规、较重违规、严重违规、涉嫌欺诈骗保
  - 引用定性依据：政策法规条款、医保协议条款
- 金额核算：
  - 违规本金：确认违规的费用金额
  - 涉及医保基金：违规费用中医保基金支付部分（区分统筹基金、个人账户）
  - 处罚金额：根据违规性质与情节，按法规计算罚款金额（如骗取金额2倍以上5倍以下罚款）
  - 金额区分：自动区分统筹区、险种（职工/居民）、基金类型
- 责任界定：
  - 机构责任：定点医药机构主体责任
  - 科室责任：涉事科室管理责任
  - 个人责任：涉事医生、药师、管理人员责任
  - 责任程度：主要责任、次要责任、连带责任
- 人工确认：AI给出建议后，由稽核员确认或调整，调整记录留痕

**输入**
- 任务结果数据包（核查结论、证据、申诉复核结果）
- 政策法规库、医保协议条款

**输出**
- 违规确认书（定性结论、金额核算、责任界定、处置建议）

#### 3.1.2 双人复核

**功能描述**
重大定性与处罚事项实行双人复核、电子签名，保障处置决定合法合规、避免独断失误。

**业务规则**
- 需双人复核的事项（可配置）：
  - 认定涉嫌欺诈骗保的
  - 违规金额≥10000元的
  - 拟解除服务协议的
  - 拟行政处罚的
  - 拟移送公安/纪检的
  - 机构申诉后改判的
- 复核流程：
  - 第一承办人完成违规确认 → 提交复核
  - 第二复核人独立审核（定性、金额、证据、程序、依据）
  - 复核通过 → 电子签名确认 → 进入下一环节
  - 复核不通过 → 退回承办人，说明复核意见，修改后重新提交
- 复核意见：通过、退回修改、需补充证据、需集体审议
- 电子签名：复核人电子签名，签名时间、IP留痕，防篡改
- 回避制度：复核人与案件有利害关系的应回避

#### 3.1.3 检查报告生成

**功能描述**
确认后自动生成规范检查报告，确保检查成果标准化、规范化，为后续处置提供正式依据。

**业务规则**
- 报告内容结构：
  - 封面：报告编号、被检机构、检查类型、检查时间、检查人员
  - 一、检查基本情况（检查依据、检查范围、检查时间、检查方式）
  - 二、检查发现问题（按违规类型分类描述，含时间、科室、人员、具体行为、金额）
  - 三、违规金额认定（分类汇总，区分险种、统筹区）
  - 四、问题性质认定（一般/较重/严重/涉嫌欺诈骗保，认定依据）
  - 五、责任界定（机构、科室、个人责任）
  - 六、处理建议（协议处理/行政处罚/移送，具体措施）
  - 七、附件（证据清单、佐证材料）
- 自动填充：从违规确认书、核查记录、证据链中自动提取数据填充
- 人工修改：支持人工编辑调整报告内容，修改留痕
- 报告编号：按规则自动生成唯一编号
- 导出格式：Word/PDF，支持在线预览

#### 3.1.4 结果推送

**功能描述**
复核通过后将结果正式推送被检机构，保障机构知情权，告知申诉权利与时限，程序公正透明。

**业务规则**
- 推送内容：检查报告、违规确认书、违规金额认定表、处理意见告知书
- 推送方式：系统站内通知 + 短信提醒 + 电子送达（带签收回执）
- 告知事项：
  - 违规事实与金额
  - 拟作出的处理决定
  - 陈述申辩权利（收到之日起5个工作日内）

#### 3.2.1 协议处理

**功能描述**
支持约谈、拒付、基金追回、暂停结算、暂停/解除服务协议等协议处理措施，是医保部门最常用的处置方式。

**业务规则**
- 协议处理措施及适用情形：
  - 约谈：违规情节较轻，首次发生，责令改正的
  - 拒付：对已确认违规费用不予支付（未结算的）
  - 基金追回：对已支付的违规基金责令退回
  - 暂停结算：违规情节较重，或整改不到位的，暂停医保费用结算
  - 暂停服务协议：严重违规，或暂停结算后仍不改正的，暂停医保服务协议（1-6个月）
  - 解除服务协议：特别严重违规，或暂停服务协议后仍不改正的，解除医保服务协议
- 处理流程：
  - 根据违规性质与情节自动匹配建议措施
  - 承办人提出处理意见 → 双人复核 → 审批
  - 生成协议处理文书（约谈通知书、拒付通知书、追回通知书、暂停/解除协议通知书）
  - 电子送达机构，签收回执
  - 执行处理措施，跟踪执行情况
- 审批层级：
  - 约谈、拒付、追回：科长审批
  - 暂停结算：处长审批
  - 暂停/解除服务协议：局长审批

#### 3.3.2 到账核销

**功能描述**
上传到账凭证并跟踪追回进度，到账后及时核销，确保资金安全、账实相符。

**业务规则**
- 到账登记：
  - 财务人员根据银行到账通知，登记到账信息（到账日期、金额、付款方、凭证号）
  - 上传银行回单/到账凭证作为附件
  - 系统自动匹配对应追回台账（按机构、金额、时间匹配）
- 核销操作：
  - 到账金额与应追金额一致 → 全额核销，状态更新为"已追回"
  - 到账金额小于应追金额 → 部分核销，状态更新为"部分追回"，剩余继续追缴
  - 到账金额大于应追金额 → 标记异常，需人工核实是否多缴/错缴
- 核销确认：核销需双人确认（经办人+复核人），电子签名留痕
- 凭证管理：到账凭证与追回台账关联归档，支持调阅
- 逾期提醒：超过追回期限未到账的，自动提醒承办人，超期30天升级处置

**功能描述**
沉淀检查标准、判定口径、违规情形定义、金额核算规则、处罚裁量基准，形成统一标准口径库并支持版本管理；自动归集已办结典型案件，结构化存储案件背景、违规事实、认定依据、处置结果、申诉改判情况，支持按违规类型、机构类型检索与案例比对；维护政策库、法规库、案例库、专家库、知识库、规则库及其时效性，定性与文书时自动匹配现行有效依据。

**业务规则**
- 标准口径库：
  - 内容：检查标准、判定口径、违规情形定义、金额核算规则、处罚裁量基准
  - 版本管理：每次修订生成新版本，保留历史版本，标注生效时间
  - 适用范围：按统筹区、机构类型、违规类型标注适用范围
  - 时效性：标注现行有效/已废止/待生效
- 典型案例库：
  - 结构化字段：案件编号、案件名称、机构类型、违规类型、违规金额、处置结果、申诉改判情况、典型意义
  - 案例标签：违规类型、机构类型、处置类型、争议焦点、指导意义
  - 检索比对：支持按多维度检索，支持案件相似度比对
  - 案例入库：办结案件经审核后自动/手动入库
- 政策法规案例库（六库）：
  - 政策库：医保政策文件、规范性文件
  - 法规库：法律、行政法规、部门规章、地方性法规

#### 3.4.4 复盘优化与模型迭代

**功能描述**
对每起办结案件开展多维度量化评分（定性准确性、程序合规性、证据完整性、文书规范性、处置适当性），重点复盘低分、申诉改判、复议撤销案件，输出复盘报告与优化建议；历史案件、核查数据、处置结果、误判反馈全量回流模型库与规则库，持续训练优化风险识别与AI研判模型，自动提出规则阈值调整建议，经人工确认后生效，实现"一次处置、一次优化、持续进化"。

**业务规则**
- 案件质量评分：
  - 评分维度（5维，各20分，总分100）：
    - 定性准确性（20分）：违规定性是否准确、问题性质认定是否恰当
    - 程序合规性（20分）：检查、告知、听证、送达、审批等程序是否合法合规
    - 证据完整性（20分）：证据链是否完整、证据是否充分、取证是否规范
    - 文书规范性（20分）：文书格式、内容、法条引用、文号是否规范
    - 处置适当性（20分）：处置措施是否与违规情节匹配、裁量是否适当
  - 评分等级：≥90优秀、80-89良好、70-79合格、<70不合格
  - 评分方式：AI初评+人工复核
- 重点案件复盘：
  - 复盘范围：评分<70分、申诉改判、复议撤销、诉讼败诉、社会影响大的案件
  - 复盘内容：问题剖析、原因分析、责任认定、改进措施
  - 复盘输出：复盘报告、问题清单、优化建议
- 模型迭代：
  - 数据回流：办结案件数据（含误判反馈）回流模型训练集
  - 模型优化：定期重训风险识别模型、AI研判模型，提升准确率
  - 规则优化：AI自动分析误判规律，提出规则阈值调整建议
  - 人工确认：规则/模型调整建议经人工审核确认后生效
  - 效果监控：持续监控识别准确率、召回率、误报率

#### 3.5.2 整改反馈复查

**功能描述**
机构在线反馈整改情况，上传整改佐证，监管审核复查是否通过，不通过的退回重改，确保整改实效、不走过场。

**业务规则**
- 机构反馈：
  - 逐项填写整改完成情况、整改措施、整改效果
  - 上传整改佐证材料（制度文件、培训记录、系统截图、财务凭证等）
  - 提交整改报告（加盖公章）
- 监管复查：
  - 材料审核：审核整改材料完整性、真实性
  - 现场复查：对重点问题、高风险机构开展现场复查
  - 数据复查：通过系统数据比对，验证整改后是否仍有同类违规
  - 复查结论：通过/不通过/部分通过
- 不通过处理：
  - 退回机构重新整改，明确重新整改要求与时限
  - 重新整改仍不通过的，升级处置（约谈、暂停结算、暂停协议）
- 整改验收：全部整改事项通过后，出具整改验收意见
- 整改超期：超期未完成整改的，自动督办并纳入信用记录

#### 3.6.1 销号条件核验

**功能描述**
自动校验定性、处置、追回、整改、文书是否齐备，确保案件处置到位、闭环完整，防止"查完就完"。

**业务规则**
- 销号必备条件（五项全部满足方可销号）：
  1. 定性完成：违规事实已确认，问题性质已认定，双人复核通过

#### 3.6.3 信用联动

**功能描述**
按规定将处置结果联动机构与个人信用记录，发挥信用监管震慑作用，构建"一处违规、处处受限"的信用监管格局。

**业务规则**
- 联动对象：
  - 机构信用：定点医药机构医保信用等级、信用档案
  - 个人信用：涉事医生、药师、管理人员的医保从业人员信用档案
  - 公共信用：按规定推送至全国信用信息共享平台、地方公共信用平台
- 联动内容：
  - 违规事实与类型
  - 处置结果（约谈、处罚、暂停/解除协议、移送）
  - 整改情况
  - 屡查屡犯记录
- 信用评价影响：
  - 机构信用等级下调（A级→B级→C级→D级）
  - 影响定点资格复审、保证金比例、稽核频次
  - D级机构暂停或解除医保协议
- 联动方式：
  - 系统自动推送至医保信用管理系统
  - 按规定定期推送至公共信用平台
  - 生成信用惩戒决定书并送达
- 信用修复：机构整改到位、一定期限内无新增违规的，可申请信用修复

### 5.3 问题性质枚举

| 性质等级 | 定义 | 典型情形 | 处置方向 |
|---|---|---|---|
| 一般违规 | 违规情节轻微，金额较小 | 小额重复收费、首次过度诊疗 | 约谈、拒付、追回、责令整改 |
| 较重违规 | 违规情节较重，金额较大或多项违规 | 重复收费涉及多科室、过度诊疗普遍 | 追回+罚款（1-2倍）、暂停结算 |
| 严重违规 | 违规情节严重，金额巨大或屡查屡犯 | 系统性欺诈骗保、屡查屡犯 | 追回+罚款（2-5倍）、暂停/解除协议 |
| 涉嫌欺诈骗保 | 主观故意骗取基金，涉嫌犯罪 | 虚构诊疗、伪造材料、串换药品 | 追回+罚款（2-5倍）、解除协议、移送公安 |

| 处置措施 | 适用情形 | 审批层级 |
|---|---|---|
| 约谈 | 情节较轻，首次违规 | 科长审批 |
| 拒付 | 未结算的违规费用 | 科长审批 |
| 基金追回 | 已支付的违规基金 | 科长审批 |
| 暂停结算 | 情节较重或整改不力 | 处长审批 |
| 暂停服务协议 | 严重违规或暂停结算后不改 | 局长审批 |
| 解除服务协议 | 特别严重违规 | 局长办公会 |
| 行政处罚 | 欺诈骗保或情节严重 | 局长审批+法制审核 |
| 移送公安 | 涉嫌犯罪 | 局长审批+法制审核 |
