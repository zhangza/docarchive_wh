# 成果宣教智能体 — 详细功能设计

> 本文档用于前端 Vibe Coding 开发，聚焦业务流程与功能逻辑，所有数据均为 Mock 数据。

---

## 一、模块概述

### 1.1 模块定位

成果宣教智能体是医保基金监管全流程的**价值迭代与延伸中枢**，承担"逆向复盘—统计分析—模型迭代—合规宣教"核心职能，将监管成果转化为数据洞察、经验沉淀、模型优化和宣教素材，实现"查处一案、警示一片、规范一方、赋能全域"。

### 1.2 解决的核心问题

- "重处置、轻复盘"，办案质量难评估
- 战果说不清、态势看不明、决策缺数据
- 规则模型不随实战进步，识别能力停滞
- 警示不足、合规引导缺位、监管价值难延伸

### 1.3 与其他智能体的关系

| 上游输入 | 本智能体 | 下游输出 |
|---|---|---|
| 疑点线索/任务/处置/文书全流程数据 | 成果宣教智能体 | → 各智能体（模型优化、规则调整） |
| 误判反馈、申诉改判数据 | | → 机构端/公众端（宣教素材推送） |

---

## 二、业务流程

### 2.1 整体业务流程

```
[全流程监管数据汇聚]
       ↓
[逆向复盘] → 案件质量评分 → 重点案件复盘 → 复盘报告
       ↓
[统计分析] → 可视化大屏 → 多维对比分析 → 效能评估 → 一键报告
       ↓
[模型迭代] → 案例数据回流 → 模型优化 → 准确率监控
       ↓
[合规宣教] → 素材生成（案例/合规/政策/指引）→ 多端分类推送 → 效果统计
```

## 三、功能详细设计

### 3.1 逆向复盘
