# 文书生成智能体 — 详细功能设计

> 本文档用于前端 Vibe Coding 开发，聚焦业务流程与功能逻辑，所有数据均为 Mock 数据。

---

## 一、模块概述

### 1.1 模块定位

文书生成智能体是医保基金监管全流程的**执法规范保障中枢**，承担"模板管理—智能生成—智能校对—签章送达—证据管理—案卷归档"全链条职能，实现监管执法文书一键规范生成、全流程线上留痕、电子案卷自动归档，从源头筑牢行政执法合规底线、规避执法风险、提升医保监管执法公信力。

### 1.2 解决的核心问题

- 文书格式不统一、到处找模板
- 信息重复录入、人工撰写慢、文号易错
- 法条引用错误、要素缺失、笔误等执法风险
- 线下签章跑腿、送达无凭证
- 证据材料零散、印证关系不清、易篡改
- 案卷人工装订繁琐、事后检索困难

### 1.3 与其他智能体的关系

| 上游输入 | 本智能体 | 下游输出 |
|---|---|---|
| 专项任务管理智能体（任务信息） | 文书生成智能体 | → 违规处置智能体（处置文书） |
| 违规处置智能体（处置决定） | | → 机构端（文书送达） |
| 疑点线索管理智能体（证据材料） | | → 档案管理（电子案卷归档） |
| 政策法规案例库（法条依据） | | → 成果宣教（典型案例素材） |

## 二、业务流程

### 2.1 整体业务流程

```
[文书模板库] → 选择文书类型与模板
       ↓
[数据自动填充] → 从任务/处置/线索数据自动带入当事人、违规事实、金额、法条
       ↓
[AI辅助撰写] → 一键生成表述规范的文书初稿
       ↓
[文号自动生成] → 按规则编制连续唯一文号
       ↓
[智能校对] → 法条引用校对 + 要素与文字校对
       ↓
[人工审核修改] → 审核人员审核确认
       ↓
[在线签章] → 电子印章 + 个人电子签名
       ↓
[电子送达] → 在线送达机构，回传已读/签收回执
       ↓
[证据全链管理] → 证据自动归集 + 证据链可视化 + 防篡改导出
       ↓
[案卷归档] → 案卷自动组装 + 一键归档检索 + 纸质扫码入档
```

### 2.2 各子流程说明

**子流程 A：文书生成流程**
1. 选择文书类型（检查通知书、询问笔录、证据清单、整改意见书、处罚决定书等）
2. 系统自动匹配对应模板
3. 从关联任务/案件数据自动填充当事人、违规事实、金额、适用法条等要素
4. AI辅助撰写文书正文，生成表述规范的初稿
5. 自动生成文号
6. 智能校对（法条、要素、文字）
7. 人工审核修改确认

**子流程 B：签章送达流程**
1. 文书审核通过后，发起在线签章
2. 加盖单位电子印章和经办人电子签名
3. 生成带签章的正式文书（PDF）
4. 通过系统在线送达被检机构/当事人
5. 机构查看/签收后回传已读、签收回执
6. 未签收的按规则视为送达或邮寄送达
7. 送达全程留痕

**子流程 C：证据管理流程**
1. 全流程证据自动归集（结算数据、诊疗记录、现场照片、笔录等）
2. 按证据类型分类（书证、物证、视听资料、电子数据、证人证言、当事人陈述、鉴定意见、勘验笔录）
3. 智能校验证据完整性与合法性
4. 证据链可视化展示（证据相互印证关系图）
5. 证据固化防篡改（哈希值、时间戳、电子签名）
6. 支持盖章导出

**子流程 D：案卷归档流程**
1. 案件办结后，自动归集全流程文书与证据材料
2. 按档案规范自动排列目录与材料顺序
3. 生成案卷目录与电子案卷
4. 纸质材料扫码上传，自动识别分类并关联电子案卷
5. 一键归档，支持按文号、机构、年度检索调阅
6. 档案借阅审批与水印下载

## 三、功能详细设计

### 3.1 文书模板库

#### 3.1.1 全套制式模板

**功能描述**
内置检查通知书、记录单、询问笔录、证据清单、整改意见书、处罚决定书、案卷目录等模板，实现制式文书标准化管理，解决文书格式不统一、到处找模板的问题。

**业务规则**
- 模板分类（按业务环节）：
  - 任务派发类：检查通知书、任务派工单
  - 现场核查类：现场检查记录单、询问笔录、证据清单、调取证据通知书
  - 结果告知类：检查结果告知书、陈述申辩告知书、听证告知书
  - 处置决定类：整改意见书、约谈通知书、追回基金通知书、暂停结算通知书、暂停/解除协议通知书、行政处罚决定书、案件移送函
  - 送达执行类：送达回证、强制执行申请书
  - 归档类：案卷目录、结案报告、备考表
- 模板要素：
  - 固定要素：文头（单位名称+文书名称）、文号、落款、日期、印章位置
  - 可变要素：当事人信息、违规事实、法律依据、处理决定、金额等（用占位符标记）
- 模板版本：每个模板维护版本号，修订后保留历史版本
- 模板适用范围：按文书类型、任务类型、机构类型标注适用范围
- 模板预览：支持在线预览模板样式

#### 3.1.2 模板维护

**功能描述**
支持按本地格式调整模板抬头、落款与印章位置，实现模板本地化适配，解决各地文书格式差异问题。

**业务规则**
- 维护权限：仅模板管理员可修改，修改需审批
- 可调整内容：
  - 文头：单位名称（如"芜湖市医疗保障局"）、文书名称字体字号
  - 文号格式：文号前缀、编号规则、年份格式
  - 落款：单位名称、日期格式、签名位置
  - 印章位置：公章位置、骑缝章位置
  - 页面设置：页边距、纸张大小、页眉页脚
- 模板编辑器：可视化编辑器，支持拖拽调整元素位置
- 版本管理：每次修改生成新版本，保留历史版本，可回滚
- 生效审批：模板修改后需经审批方可生效，生效前不影响在用文书
- 模板导入导出：支持Word模板导入、导出

### 3.2 文书智能生成

#### 3.2.1 数据自动填充

**功能描述**
自动带入当事人、违规事实、金额与适用法条，解决信息重复录入、人工撰写慢的问题，实现文书一键生成。

**业务规则**
- 数据来源：
  - 任务信息：任务编号、被检机构、检查时间、检查人员
  - 违规确认：违规类型、违规事实、违规金额、涉及基金、问题性质
  - 处置决定：处置措施、处罚金额、法律依据
  - 机构信息：机构名称、地址、法定代表人、联系方式
  - 人员信息：涉事医生、科室、职务
- 填充规则：
  - 根据文书类型自动匹配需要填充的字段
  - 从关联案件数据中自动提取并填充到对应占位符
  - 金额自动大写转换（如"12345.67元"→"壹万贰仟叁佰肆拾伍元陆角柒分"）
  - 日期自动格式化
  - 法条自动引用（根据违规类型匹配对应法规条款）
- 填充校验：填充后自动校验必填字段是否完整，缺失项标红提示
- 人工修改：自动填充后支持人工修改调整

#### 3.2.2 AI辅助撰写

**功能描述**
一键生成表述规范的文书初稿，利用医疗大模型与法律知识库，确保文书表述专业、逻辑严密、符合执法文书规范。

**业务规则**
- AI撰写内容：

### 3.3 智能校对

#### 3.3.1 法条引用校对

**功能描述**
校验法规条款准确性与现行有效性，解决法条引用错误、引用失效条文等执法风险，确保文书法律适用准确。

**业务规则**
- 校对内容：
  - 法规名称准确性：是否存在错字、漏字、简称不规范

  - 条文内容一致性：引用的条文内容与法规库是否一致

#### 3.3.2 要素与文字校对

**功能描述**
检查要素齐全、金额一致及错别字等问题，解决文书要素缺失、金额前后不一致、笔误等问题，保障文书严谨规范。

**业务规则**
- 要素检查：
  - 当事人信息完整性（名称、地址、法定代表人、联系方式）
  - 违规事实五要素（时间、地点、人物、行为、金额）
  - 法律依据完整性（法规名称+条款号）
  - 处理决定完整性（处置措施+金额+履行期限）
  - 权利告知完整性（复议机关+复议期限+诉讼法院+诉讼期限）
  - 落款完整性（机关名称+日期+印章位置）
- 一致性检查：
  - 金额一致性：正文金额与金额大写、与表格金额、与处罚决定金额是否一致
  - 当事人名称一致性：全文当事人名称是否统一
  - 日期一致性：违规时间、检查时间、决定时间逻辑是否合理
  - 文号一致性：文号与文书类型、年份是否匹配
- 文字校对：
  - 错别字、漏字、多字
  - 标点符号规范
  - 数字用法规范（金额大写、日期格式）
  - 法言法语规范性（口语化表述提示）
- 校对结果：
  - 错误（红）：要素缺失、金额不一致、错别字
  - 警告（黄）：表述不规范、标点不规范
  - 提示（蓝）：建议优化表述
- 一键修正：对明显错误支持一键修正

### 3.4 签章与送达

#### 3.4.1 在线签章

**功能描述**
支持电子印章与个人电子签名，解决线下签章跑腿、效率低的问题，实现文书签章全流程线上化、留痕化。

**业务规则**
- 签章类型：
  - 单位电子印章：公章、合同专用章、财务专用章等
  - 个人电子签名：法定代表人签名、经办人签名、审核人签名
- 签章流程：
  1. 文书审核通过后，发起签章申请
  2. 选择需要加盖的印章类型和签名人
  3. 签章人身份核验（密码/短信验证码/生物识别）
  4. 系统自动在指定位置加盖电子印章和电子签名
  5. 生成带签章的正式PDF文书
  6. 签章记录留痕（签章人、签章时间、IP地址、文书哈希值）
- 签章权限：
  - 按岗位配置签章权限（如处罚决定书需局长签章）
  - 重要文书需多级签章（经办人→部门负责人→单位负责人）

- 电子印章管理：
  - 印章图片备案（与实物印章一致）
  - 印章使用授权
  - 印章使用日志
  - 印章挂失/换发
- 防篡改：签章后文书固化，任何修改都会使签章失效，需重新签章

#### 3.4.2 电子送达

**功能描述**
在线送达机构并回传已送达、已读、签收回执，解决线下送达跑腿、送达无凭证的问题，实现送达全流程线上留痕。

**业务规则**
- 送达方式：
  - 系统站内送达：通过机构端系统推送文书
  - 短信送达：发送短信通知，附文书查看链接
  - 电子邮件送达：发送至机构预留邮箱
  - 邮寄送达：电子送达失败时转邮寄（EMS）
  - 直接送达：特殊情况现场直接送达
- 送达流程：
  1. 文书签章完成后，发起电子送达
  2. 选择送达方式（可多选）
  3. 系统推送文书至机构端，同时发送短信/邮件通知
  4. 机构查看文书，系统记录已送达时间
  5. 机构阅读文书，系统记录已读时间、阅读时长
  6. 机构签收确认（电子签名），生成签收回执
  7. 送达完成，送达回证自动归档
- 送达状态：
  - 待送达：已发起未推送
  - 已送达：已推送至机构端
  - 已读：机构已查看文书
  - 已签收：机构已签收确认
  - 送达失败：推送失败（机构未激活、联系方式错误）
  - 视为送达：电子送达后一定期限未签收，按规定视为送达
- 视为送达规则（可配置）：
  - 系统站内送达：推送后72小时未签收，视为送达
  - 短信/邮件送达：发送后72小时未查看，视为送达
  - 邮寄送达：签收或退回之日为送达日期
- 送达回证：自动生成，包含送达文书名称、文号、送达方式、送达时间、签收人、签收时间

#### 3.5.2 证据链可视化

**功能描述**
以链条图直观展示证据相互印证关系，解决证据印证关系不清、逻辑不直观的问题，帮助办案人员快速把握证据体系。

**业务规则**
- 可视化形式：
  - 证据链图：以违规事实为中心，关联相关证据，展示印证关系
  - 时间轴图：按时间顺序展示证据形成过程
  - 关系图谱：展示证据之间、证据与当事人之间、证据与违规行为之间的关联关系
- 印证关系类型：
  - 直接证明：证据直接证明违规事实
  - 间接证明：证据通过推理证明违规事实
  - 相互印证：多份证据相互佐证同一事实
  - 矛盾冲突：证据之间存在矛盾（需重点标注）
- 交互功能：
  - 点击证据节点查看证据详情
  - 拖拽调整布局
  - 放大缩小、全屏查看
  - 按证据类型筛选显示
  - 导出图片/PDF
- 证据链完整性标识：
  - 完整（绿色）：违规事实有充分证据支撑，证据间相互印证
  - 基本完整（黄色）：证据基本充分，个别环节可加强
  - 不完整（红色）：关键证据缺失或证据间存在矛盾

#### 3.5.3 防篡改导出

**功能描述**
证据固化、可溯源，支持盖章导出，解决证据易篡改、法律效力不足的问题，确保证据真实、完整、可信。

**业务规则**
- 证据固化技术：
  - 哈希值校验：每份证据生成SHA-256哈希值，任何修改都会导致哈希值变化
  - 时间戳：每份证据标注精确到秒的采集/固化时间
  - 电子签名：采集人、固化人电子签名确认
  - 区块链存证：关键证据哈希值上链存证（可选）
  - 只读存储：固化后的证据设为只读，不可修改删除
- 溯源功能：
  - 证据全生命周期追溯：从采集、传输、存储、使用到归档全程留痕
  - 操作日志：任何人查看、下载、导出证据都有记录
  - 证据来源可查：每份证据可追溯到原始来源、采集人、采集时间
- 盖章导出：
  - 导出证据时加盖"证据专用章"电子印章
  - 导出文件添加水印（案件编号、导出人、导出时间、页码）
  - 生成证据清单（含证据编号、名称、类型、哈希值、页码）
  - 导出格式：PDF（单份/合并）、ZIP（原件+清单+校验工具）
- 校验工具：
  - 提供哈希值校验工具，接收方可验证证据是否被篡改
  - 校验报告：导出时自动生成证据完整性校验报告

#### 3.6.1 案卷自动组装

**功能描述**
按档案规范自动排列目录与材料顺序，解决案卷人工装订繁琐、排列不规范的问题，实现电子案卷标准化组装。

**业务规则**
- 案卷组装规则（按行政执法档案规范）：
  - 案卷封面：案件名称、案卷编号、案由、当事人、立案时间、结案时间、保管期限、归档号
  - 卷内目录：按材料顺序排列，含序号、材料名称、日期、页号、备注
  - 材料顺序（一般规则）：
    1. 立案审批材料（立案审批表、线索来源材料）
    2. 检查通知材料（检查通知书、送达回证）
    3. 现场检查材料（检查笔录、证据清单、调取证据通知书）
    4. 询问笔录（按时间顺序）
    5. 证据材料（按证据类型分类，书证、物证照片、视听资料说明、电子数据说明、鉴定意见、勘验笔录）
    6. 当事人陈述申辩材料
    7. 审理审查材料（案件调查终结报告、法制审核意见、集体讨论记录）
    8. 告知材料（事先告知书、听证告知书、送达回证）
    9. 听证材料（听证申请、听证通知书、听证笔录、听证报告）

  - 备考表：立卷人、检查人、立卷时间、备注

#### 3.6.2 一键归档检索

**功能描述**
一键归档电子案卷，支持按文号、机构、年度检索调阅，解决事后检索困难、调阅繁琐的问题，实现档案高效管理。

**业务规则**

  - 归档后案卷设为只读，不可修改（如需修改需审批解锁）
  - 归档信息自动登记（归档号、案件名称、归档时间、保管期限、档案位置）
- 检索功能：
  - 关键词检索：全文检索文书内容、证据内容
  - 条件检索：按文号、机构名称、法定代表人、违规类型、处罚结果、立案时间、结案时间、保管期限、归档号等多维度组合检索
  - 模糊检索：支持机构名称简称、文号片段等模糊匹配
  - 高级检索：支持多条件组合、时间范围、金额范围等

  - 在线预览：案卷目录、文书内容、证据材料在线预览
  - 案卷浏览：按卷浏览，支持翻页、放大、缩略图导航

  - 借阅期限：设置借阅期限，到期自动归还
  - 借阅记录：全程记录借阅人、借阅时间、查阅内容、下载记录
- 档案统计：
  - 按年度、类型、机构统计归档数量
  - 档案利用统计（查阅次数、下载次数、借阅次数）

#### 3.6.3 纸质案卷扫码入档

**功能描述**
支持纸质案卷材料扫码上传、自动识别分类并关联对应电子案卷，实现纸质与电子档案一体化管理，解决纸质档案数字化繁琐、关联困难的问题。

**业务规则**
- 扫码入档流程：
  1. 纸质材料整理排序（按案卷目录顺序）
  2. 使用高拍仪/扫描仪批量扫描
  3. 系统自动OCR识别每份材料的标题、文号、日期等关键信息
  4. 自动匹配电子案卷中对应的文书/证据条目
  5. 自动分类归入对应位置
  6. 人工确认匹配结果，对未匹配的手动关联
  7. 关联后电子案卷中可查看纸质扫描件
- 自动识别分类：
  - 文书类型识别：根据标题、文号格式识别文书类型（处罚决定书、通知书、笔录等）
  - 日期识别：识别文书落款日期
  - 文号识别：识别文书编号，用于精准匹配
  - 当事人识别：识别机构/人员名称
  - 页码识别：自动编排页码
- 匹配规则：
  - 精准匹配：文号完全一致 → 自动匹配
  - 模糊匹配：文书类型+日期+当事人匹配 → 建议匹配
  - 未匹配：无法识别的 → 人工分类
- 质量控制：
  - 扫描质量检测（清晰度、倾斜度、完整性）
  - 模糊/缺页自动提示重扫
  - 扫描件与电子件比对（内容一致性校验）
- 纸质档案管理：
  - 纸质档案位置登记（库房、排、层、格）
  - 纸质档案借阅登记
  - 纸质与电子档案关联查询
  - 纸质档案销毁审批（到期后）
