## 一之二、平台统一入口（门户）

门户是**跨智能体**的平台首页，不属于任何单个智能体，因此独立成域：

| 层 | 路径 | 说明 |
|---|---|---|
| 页面 | `src/features/portal/Portal.vue` | 独立全屏页，不套 `MainLayout` |
| 接口 | `src/api/shared/portal.ts` | `getPortalAgents` / `getPortalOverview` |
| Mock | `mock/shared/portal.ts` | `/api/portal/agents`、`/api/portal/overview` |
| 数据 | `mock/shared/data/agents.ts` | **智能体卡片元数据唯一来源** |
| 路由 | `src/router/index.ts` 的 `PORTAL_PATH` | `/portal`，且 `/` 与未匹配路由均重定向至此 |

新增智能体上线时，需同步更新两处：
1. `src/router/index.ts` 的 `AGENTS` —— 把 `ready` 改为 `true`（控制菜单）
2. `mock/shared/data/agents.ts` 的 `AGENT_CARDS` —— 把 `ready`、`pageCount`、`entry` 补齐，并给 `features[].path` 填上已实现页面路由（控制门户卡片）

门户与主壳的互通：主壳顶栏的品牌区与「智能体矩阵」按钮均可返回 `/portal`。

## 三、跨智能体共享层

共享资产**不放进任何 agent 目录**，避免相互依赖：

| 路径 | 用途 |
|---|---|
| `src/api/request.ts` | axios 实例、拦截器 |
| `src/api/shared/common.ts` | 跨智能体公共接口（用户、字典、机构、导出等） |
| `src/components/base/` | 基础组件（自动注册，无需 import） |
| `src/components/business/` | 通用业务组件（自动注册） |
| `src/assets/styles/tokens.scss` | Design Token —— 唯一色值来源 |
| `src/assets/styles/index.scss` | 全局样式与工具类 |
| `src/stores/` | 全局状态（user / dict / clue） |
| `src/types/business.ts` | 共享业务类型 |
| `src/utils/format.ts` | 格式化、图表配色常量 |
| `mock/shared/data/` | **Mock 数据集（口径唯一来源，全智能体共用）** |
| `mock/shared/utils.ts` | Mock 工具（ok / delay / paginate / filterBy） |
| `mock/shared/common.ts` | 公共 Mock 接口 |

### 依赖方向（严格单向）

```
共享层  →  智能体模块  →  页面
```

- ✅ 智能体模块可以依赖共享层
- ❌ 共享层**不得**依赖任何智能体模块
- ❌ 智能体之间**不得**相互 import；需要共用的代码上提到共享层

**边界自检**：删掉任意一个 `agentNN-*` 目录，其余代码只应报「该模块缺失」，不应连环崩塌。

## 四、新增一个智能体的标准步骤

以智能体二（专项任务管理）为例：

**1. 建页面** —— `src/features/agent02-task/<业务域>/XxxPage.vue`

**2. 建接口封装** —— `src/api/agent02-task/<业务域>.ts`

```ts
import { get, post } from '../request'

export const getTaskList = (params?: any) => get<any>('/task/list', params)
```

**3. 建 Mock 接口** —— `mock/agent02-task/<业务域>.ts`

```ts
import type { MockMethod } from 'vite-plugin-mock'
import { ok, delay, paginate } from '../shared/utils'
import { ORGS } from '../shared/data/base'   // 复用共享数据集，保证口径一致

export default [
  {
    url: '/api/task/list',
    method: 'get',
    response: async ({ query }: any) => {
      await delay()
      return ok(paginate(/* ... */))
    }
  }
] as MockMethod[]
```

> Mock 新增数据集时放入 `mock/shared/data/`，**不要在接口文件里写死数据**，否则跨页面数值会不一致。

**4. 填路由** —— 编辑 `src/router/agent02-task.ts`，把路由写入 `AGENT02_ROUTES`

**5. 开启菜单** —— 在 `src/router/index.ts` 把该智能体的 `ready` 改为 `true`

> `vite.config.ts` 与 `index.ts` 的聚合逻辑**无需改动**，新目录会被自动识别。

## 五、Mock 加载规则

`vite.config.ts` 中 `viteMockServe` 的 `ignore` 回调收到的是**相对 `mock/` 的 POSIX 路径**。当前规则：

- 加载：`agentNN-*/**.ts`、`shared/common.ts`
- 排除：`shared/utils.ts`、`shared/data/**`、任何 `_` 开头的文件（草稿/私有片段）

## 六、页面编码规范（摘要）

- 根元素 `<div class="zh-page">`，页头用 `<PageHeader title subtitle tag="MXX">`；机构端加 `tag-tone="accent"`
- 分区用 `.section-card`（`--tight` / `--flat`），区标题用 `.section-title` + `__dot` / `__text` / `__desc`
- 查询区按钮顺序：展开 → 查　询 → 重　置（含全角空格）
- 样式**只用** Design Token `var(--zh-*)`；字面色值仅允许出现在 ECharts option 内
- 表格统一 `size="small" border stripe`，数值右对齐加 `.num`，空态用 `<EmptyState />`
- 不要 import `ref`/`computed`/`ElMessage`/`useRouter` 等，已由 `unplugin-auto-import` 自动注入
- ⚠️ auto-import 的符号**只能在 `<script setup>` 中使用**；模板内需调用时先在 script 起别名：`const msg = ElMessage`
- 11 个共享组件已自动注册，直接用标签即可，无需 import

## 七、构建说明

`package.json` 的 build 顺序为 `vite build && vue-tsc --noEmit`。

原因：`unplugin-auto-import` / `unplugin-vue-components` 会在 Vite 启动时**把生成的 `.d.ts` 清空**、结束时才重写。若让 `vue-tsc` 先跑，会读到空的 dts 并爆出上百条虚假的 `TS2304 Cannot find name 'ref'`。
