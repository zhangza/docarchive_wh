# "智行合医"六大智能体功能设计（初稿 v1.2）

> 本稿仅明确六大模块"建什么、实现什么、解决什么问题"，用于初步对齐需求范围。每个功能组先一句话说明其解决的问题，再以一句话说明各功能点建设内容。
>
> v1.2 更新说明：① 第一智能体名称更正为"疑点线索管理智能体"；② 1.0 全量数据比对重新定位为"基于数据关系自动发现疑点线索"，含数据接入、分析引擎、五类比对场景、结果展现；③ 3.4 台账与经验沉淀简化归并为 4 个功能点。

## 一、疑点线索管理智能体

### 1.0 全量数据比对

> **解决什么问题：** 解决医保结算数据与医院诊疗数据、药店进销存数据等多源数据相互割裂、无法交叉验证的问题。通过医保医疗数据融合，基于数据间关联关系自动比对分析，发现数据不一致、逻辑矛盾、异常关联等情况，生成疑点线索，为后续线索研判提供精准输入。

| 功能 | 建设内容 |
|---|---|
| 多源数据接入融合 | 接入医保结算、电子病历、处方、PACS 检查报告、药品进销存、诊疗记录等多源数据，完成数据融合与标准化映射，为跨源比对分析奠定基础。 |
| 智能比对分析引擎 | 基于数据间关联关系，内置多类比对算法模型，自动识别跨源数据不一致、异常关联、逻辑矛盾等问题，生成疑点线索并推送至线索研判环节。 |
| 药品进销存与结算比对分析 | 比对药店/医院药品进货量、库存量与医保结算报销量，识别超量销售、账实不符、虚假销售、药品回流等疑点。 |
| 电子病历与结算比对分析 | 比对病历记载的诊断、诊疗项目、用药与医保结算费用明细，识别串换项目、无指征收费、过度诊疗、病历与费用不符等疑点。 |
| 处方与结算比对分析 | 比对处方开具的药品名称、剂量、频次、疗程与医保结算数据，识别超量开药、重复开药、串换药品、超适应症用药等疑点。 |
| 检查检验与收费比对分析 | 比对 PACS/LIS 等系统实际检查检验报告与结算收费项目，识别虚记费用、重复收费、套餐式检查、做少收多等疑点。 |
| 参保人就医行为跨源比对分析 | 跨机构、跨时段比对同一参保人的就医、住院、开药、结算记录，识别重复住院、分解住院、频繁就医、超量购药、冒名就医等疑点。 |
| 比对分析结果展现 | 以疑点清单、统计看板、趋势图表等形式展现比对分析结果，支持按比对类型、风险等级、机构、时间等维度筛选钻取，疑点一键流转至线索研判工作台。 |

### 1.1 智能预警

> **解决什么问题：** 变"人工事后翻数据"为"系统实时主动发现"，解决线索发现滞后、依赖人工、漏判误判多的问题，做到疑点早发现、早预警。

| 功能 | 建设内容 |
|---|---|
| 多源数据实时监测 | 接入结算、处方、电子病历、药品目录等数据，7×24 小时不间断扫描。 |
| 违规疑点智能识别 | 基于规则引擎与医疗大模型，自动识别超量开药、虚假诊疗、串换、重复收费、过度诊疗等疑点。 |
| 风险自动分级分类 | 自动标注高/中/低风险、违规类型及涉事机构、科室、人员。 |
| 标准化线索库 | 统一线索编号与字段，形成可检索、可跟踪的疑点线索池。 |
| 实时预警看板 | 滚动展示新增疑点、风险分布与变化趋势。 |

### 1.2 线索研判

> **解决什么问题：** 解决高低风险线索混杂、靠个人经验判断、研判依据不透明的问题，辅助稽核员快速、精准、可解释地定性。

| 功能 | 建设内容 |
|---|---|
| 线索工作台 | 集中待办线索，支持多维筛选、分派与批量处置。 |
| 线索详情 | 一屏呈现线索信息、命中明细、AI 结论与流转记录。 |
| AI 研判建议 | 给出疑点结论、判定依据、置信度与建议动作，由人工确认采纳。 |
| 临床合理性判定 | 区分违规行为与慢病长处方、重症等合理诊疗场景，避免误判。 |
| 知识图谱溯源 | 关联参保人、医生、机构、药品、费用关系，支持一键溯源钻取。 |

### 1.3 线上筛查

> **解决什么问题：** 解决机构自查与医保数据脱节、材料反复补正、线上无法初判的问题，把问题尽量在线上查清。

| 功能 | 建设内容 |
|---|---|
| 机构在线自查 | 定点机构在线填写说明、上传佐证、提交自查报告。 |
| 数据自动比对 | 自动比对自查数据与医保原始数据，差异处标红。 |
| 材料智能校验 | 自动校验材料完整性、关联性并提示补正。 |
| 线上初筛结论 | 自动区分合理说明、存疑线索、违规苗头三类结果。 |

### 1.4 线下核查

> **解决什么问题：** 解决现场取证繁琐、纸质资料易丢失、证据回传慢、不规范的问题，实现移动化、标准化取证。

| 功能 | 建设内容 |
|---|---|
| 核查取证清单 | 按疑点自动生成现场核查事项清单，支持移动端使用。 |
| OCR 智能采集 | 拍照识别处方、病历、票据等纸质资料并结构化。 |
| 核查记录 | 支持病历核验、处方比对、库存盘点、问询笔录记录。 |
| 证据回传固化 | 支持离线操作、在线同步，证据实时回传并电子签名留痕。 |
| 自动抽取专家 | |

### 1.5 机构申诉

> **解决什么问题：** 解决机构申辩渠道不畅、沟通过程不留痕、争议难追溯的问题，保障程序公正与结果准确。

| 功能 | 建设内容 |
|---|---|
| 申诉在线提交 | 机构在线提交申诉理由、医学依据及佐证材料。 |
| AI 申诉初核 | 自动校验材料并辅助研判申诉合理性，供人工决策。 |
| 申诉复核 | 结合核查与申诉材料作出最终研判结论。 |
| 申诉反馈 | |

### 1.6 线索全周期管理

> **解决什么问题：** 解决线索处置状态不清、误判经验无法沉淀复用的问题，实现全程可跟踪、可反哺优化。

| 功能 | 建设内容 |
|---|---|
| 状态跟踪 | 线索从发现到办结各状态全程可视、闭环留痕。 |
| 误判反馈沉淀 | 记录驳回与误判原因，反哺识别模型优化。 |

## 二、专项任务管理智能体模块

### 2.1 任务智能生成

> **解决什么问题：** 解决人工归并线索、立项标准不一、重复立项的问题，实现任务快速、规范生成。

| 功能 | 建设内容 |
|---|---|
| 线索智能聚类 | 按区域、机构、科室、违规类型、风险等级自动归并同类线索。 |
| 合并去重 | 自动剔除重复、交叉线索，避免重复立项。 |
| 任务要素生成 | 自动预填检查范围、疑点清单、时限、责任人与人员分组。 |
| 多类型任务 | 支持专项检查、日常稽核、飞行检查、联合督查等任务。 |

### 2.2 任务自动派发

> **解决什么问题：** 解决人工线下派单慢、签收无跟踪、通知不到位的问题，实现任务精准直达、限时响应。

| 功能 | 建设内容 |
|---|---|
| 多方式派发 | 支持批量派发、定向派发、按风险分级派发。 |
| 限时签收 | 任务秒级推送、限时签收，未签收自动提醒并升级。 |
| 派发同步带文书 | 派发任务时同步生成检查记录单等空白文书。 |（一套文书样式、流程）

### 2.3 任务进度管控

> **解决什么问题：** 解决任务进度不透明、超期无人管、全靠人工催办的问题，实现全程可视、自动督办。

| 功能 | 建设内容 |
|---|---|
| 进度可视化 | 以流程/泳道图展示派发、签收、自查、核查、申诉、处置各节点状态。 |
| 超时督办 | 提供临期预警、超期标红、一键催办与多渠道提醒。 |
| 任务看板 | 以看板/列表双视图统计各状态任务分布。 |

### 2.4 任务结果管理

> **解决什么问题：** 解决多源结果汇总难、人工撰写慢、口径不统一的问题，实现结果自动整合与规范输出。

| 功能 | 建设内容 |
|---|---|
| 结果自动整合 | 自动汇总线上筛查、线下核查、申诉及佐证材料。 |
| 初步结果生成 | AI 生成违规内容、违规金额、问题性质与处理意见，人工复核修正。 |

## 三、违规处置智能体模块

### 3.1 违规智能确认

> **解决什么问题：** 解决定性靠经验、金额核算繁、责任难界定的问题，辅助精准、合规地认定违规。

| 功能 | 建设内容 |
|---|---|
| AI 辅助定性 | 辅助开展违规定性、金额核算与责任界定。 |（关键点）
| 双人复核 | 重大定性与处罚事项实行双人复核、电子签名。 |
| 检查报告生成 | 确认后自动生成规范检查报告。 |
| 结果推送 | 复核通过后将结果正式推送被检机构。 |

### 3.2 分类处置

> **解决什么问题：** 解决协议处理、行政处罚、移送司法路径不清、程序严易出错的问题，实现分类规范办理。

| 功能 | 建设内容 |
|---|---|
| 协议处理 | 支持约谈、拒付、基金追回、暂停结算、暂停/解除服务协议。 |
| 行政处罚 | 自动生成处罚决定书等成套案卷，支持在线签章与电子送达。 |
| 移送处理 | 涉嫌犯罪移送公安、违纪移送纪检，并生成移送文书与清单。 |
| 处置依据推荐 | 智能匹配政策、法规、案例作为定性处置依据。 |

### 3.3 基金追回

> **解决什么问题：** 解决追回进度不清、到账无跟踪的问题，确保违规基金应追尽追。

| 功能 | 建设内容 |
|---|---|
| 追回台账 | 登记应追、已追、未追金额及追回方式。 |
| 到账核销 | 上传到账凭证并跟踪追回进度。 |

### 3.4 台账与经验沉淀

> **解决什么问题：** 解决任务资料分散、检查标准与经验无法复用、监管成果说不清、决策缺数据的问题，实现全流程数据统一归档、多维度统计分析、经验持续沉淀复用，推动监管从"被动处置"向"数据驱动、智能迭代"转型。

| 功能 | 建设内容 |
|---|---|
| 全流程台账归档 | 对线索、任务、核查、处置、申诉、整改、销号全流程数据统一归档，每条线索、每项任务、每次处置、每份材料均生成唯一标识，实现来源可查、去向可追、责任可究、全程可溯；支持纸质案卷扫码上传、自动识别分类并关联电子案卷，实现纸质与电子档案一体化管理。 |
| 监管战果统计分析 | 自动统计检查人次、覆盖医院/药店数量、疑点数、阳性率、违规金额（区分统筹区、险种、违规类型）、处罚金额（区分统筹区、险种）、基金追回金额、整改完成率等核心指标，支持处罚结果分类统计、违规态势智能研判、多维交叉对比与钻取分析、成果效能评估；通过监管可视化大屏集中展示，一键生成监管分析报告与专项检查总结报告。 |
| 标准与案例经验沉淀 | 沉淀检查标准、判定口径、违规情形定义、金额核算规则、处罚裁量基准，形成统一标准口径库并支持版本管理；自动归集已办结典型案件，结构化存储案件背景、违规事实、认定依据、处置结果、申诉改判情况，支持按违规类型、机构类型检索与案例比对；维护政策库、法规库、案例库、专家库、知识库、规则库及其时效性，定性与文书时自动匹配现行有效依据。 |
| 复盘优化与模型迭代 | 对每起办结案件开展多维度量化评分（定性准确性、程序合规性、证据完整性、文书规范性、处置适当性），重点复盘低分、申诉改判、复议撤销案件，输出复盘报告与优化建议；历史案件、核查数据、处置结果、误判反馈全量回流模型库与规则库，持续训练优化风险识别与 AI 研判模型，自动提出规则阈值调整建议，经人工确认后生效，实现"一次处置、一次优化、持续进化"。 |

### 3.5 整改跟踪

> **解决什么问题：** 解决问题整改无人盯、整改不实、屡查屡犯的问题，实现整改闭环管理。

| 功能 | 建设内容 |
|---|---|
| 整改清单 | 逐项下达整改问题、要求与办理时限。 |
| 整改反馈复查 | 机构在线反馈整改情况，监管审核复查是否通过。 |

### 3.6 闭环销号

> **解决什么问题：** 解决"查完就完"、处置形不成闭环的问题，确保处置、追回、整改到位方可结案。

| 功能 | 建设内容 |
|---|---|
| 销号条件核验 | 自动校验定性、处置、追回、整改、文书是否齐备。 |
| 销号审批 | 满足条件后提交审批，核准销号并闭环标识。 |
| 信用联动 | 按规定将处置结果联动机构与个人信用记录。 |

### 4.2 文书智能生成

## 五、成果宣教智能体模块

### 5.1 逆向复盘

> **解决什么问题：** 解决"重处置、轻复盘"、办案质量难评估的问题，沉淀经验并驱动持续优化。

| 功能 | 建设内容 |
|---|---|
| 案件质量评分 | 对每起办结案件开展多维度量化评分。 |
| 重点案件复盘 | 重点复盘低分、申诉改判、复议撤销案件。 |
